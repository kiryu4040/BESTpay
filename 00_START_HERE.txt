====================================================
  BESTpay v2 へようこそ 〜 まずこのファイルを読んでください
====================================================

これは「BESTpay v2」という Android アプリの設計図（ソースコード）一式です。
あなたがやることは、たった1つだけです。

  【このフォルダの中身を、そのまま GitHub の新しいリポジトリに
    アップロードする】

それだけで、GitHub の上で自動的にアプリ本体（APK）が作られ、
スマホにインストールできるようになります。
パソコンで難しい操作（コマンド入力など）をする必要はありません。

----------------------------------------------------
■ このフォルダに入っているもの（1画面版）
----------------------------------------------------

  00_START_HERE.txt …… このファイル。説明書。
  README.md ……………… GitHub のトップページに表示される案内。
                        APK の受け取り方が詳しく書いてあります。

  lib/ …………………… アプリ本体（画面と計算の仕組み）
  test/ ………………… 計算が正しいか自動チェックするテスト
  android/ …………… Android アプリにするための土台
  tool/ ………………… 設計ルールを自動チェックする道具
  docs/ ………………… 設計の決定記録・カード追加の手順書

  .github/ ……………… 自動ビルドの設定（超重要！）
                        ※ドットで始まる名前なので見落としやすい。
                        必ずこのフォルダごとアップロードしてください。

  pubspec.yaml など … アプリの設定ファイル。触らなくてOK。

----------------------------------------------------
■ 3ステップの全体像
----------------------------------------------------

  ステップ1: GitHub で新規リポジトリを作り、このフォルダの
             中身を全部アップロードする（.github も忘れずに）

  ステップ2: GitHub 上の「Actions」タブを開き、ビルドが
             緑色のチェックマークで終わるのを待つ（5〜10分）

  ステップ3: 同じページの下の方にある「Artifacts」の
             「BestPay-APK」をダウンロードし、中の
             BestPay.apk をスマホに入れる

  ※ くわしい手順は README.md に書いてあります。

----------------------------------------------------
■ 今の状態について（大事）
----------------------------------------------------

  ・アプリは起動し、5つのタブ（ホーム/店舗/電卓/年間/設定）が
    動きます。
  ・ただしカードのデータは「まだ空」です。画面に
    「カタログはまだ空です」と出るのは正常で、故障ではありません。
  ・カードを追加するときは docs/decisions/ フォルダの中の
    card_addition_runbook.md（カード追加の手順書）を読んでください。
    計算の仕組みはすでに正しく入っているので、カードが増えても
    作り直しは不要です。
